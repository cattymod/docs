# CattyMod Extensions Docs

Here you will find documentation related to extensions in CattyMod! Not all extensions will be documented here however.

You can see all the extensions from CattyMod [here](https://cattymod.app/extensions) in the CattyMod Extension Gallery!

## Avaliable extensions
- [Modals](https://cattymod.app/extensions/modals.js) - Create Scratch 3 style popup windows, embeds, and interactive prompts.
- [Python](https://cattymod.app/extensions/python.js) - Run Python code and integrate Python scripts directly into your projects.
