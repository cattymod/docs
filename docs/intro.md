# CattyMod Docs

[CattyMod](https://studio.cattymod.app/) is a mod of Scratch with improved performance, dark mode, addons, and more. This is the place where its extra documentation goes.

Related projects:

 - [CattyMod Desktop](https://cattymod.app/desktop/)
 - [CattyMod Extension Gallery](https://cattymod.app/extensions/)
 - [Scrooch 3](https://scrooch.cattymod.app/)

These pages are [open source](https://github.com/cattymod/docs) if you want to create your own docs.
