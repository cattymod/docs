# Tabs Mode

Tabs Mode lets you open and work on **multiple Scratch projects at the same time** without closing your current project.

The editor used is powered by [Limited Editor](limited-editor.md).

## Features

- Switch between multiple projects quickly
- Keep projects open for reference or copying assets
- Work on different projects in separate tabs
- Keep each project workspace separate

## How to Open Tabs Mode

To open Tabs Mode:

1. Open the **File** menu
2. Click **New Tab**
3. CattyMod will redirect to Tabs Mode
