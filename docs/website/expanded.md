# Expanded Settings

CattyMod has an extended variety of configuration options avaliable in the Settings menu by clicking "Expand". You can also click "Settings" in various areas of the site where the regular navbar is.

Below are the options avaliable, excluding ones already in Settings.

### Custom Default Project

Custom Default Project lets you change the default [Dango Project](https://studio.cattymod.app/editor) to something you want it to be. Say ScratchCat or a custom sprite! Just input the project ID from [Scratch](https://scratch.mit.edu) and it'll show up.

### Mobile Touch Controls

Enabled by default, Mobile Touch Controls makes it so when you are in Fullscreen mode and are in portrait mode, you'll have some controls for mobile devices popping up. You can disable this option to hide the controls and make them never appear.
