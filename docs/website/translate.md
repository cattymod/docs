# Help Translate CattyMod & TurboWarp

As CattyMod itself doesn't have ways to translate it, you can translate [TurboWarp](https://turbowarp.org/) instead as CattyMod is usually in sync with TurboWarp's updates.

[Click here](https://docs.turbowarp.org/translate) to see how to do it.
