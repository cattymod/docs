# CattyMod Packager

:::info
Use the CatyMod Packager here: https://cattymod.app/packager/
:::

CattyMod Packager converts CattyMod projects into HTML files, zip archives, or executable programs for Windows, macOS, and Linux. Think turning your project into an app or webpage!
