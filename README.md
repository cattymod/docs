# CattyMod Docs

https://cattymod.app/docs

This repository contains documentation for CattyMod.

## Writing content

If you found a typo or have a suggestion to improve the pages, the easiest way to get it resolved is to post about it on CattyMod Feedback: https://cattymod.app/feedback.

## Local Development

This website is built with [Docusaurus](https://docusaurus.io/). Documentation is inside the `docs` folder, generally that is all you will have to touch.

```bash
npm install
# For development:
npm start
# For production:
npm run build
```
