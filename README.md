# CattyMod Docs

https://docs.cattymod.app/

This repository contains documentation for CattyMod.

## Writing content

If you found a typo or have a suggestion to improve the pages, the easiest way to get it resolved is to post about it on the Scratch Project Link here: https://scratch.mit.edu/projects/1335032585/

## Local Development

This website is built with [Docusaurus](https://docusaurus.io/). Documentation is inside the `docs` folder, generally that is all you will have to touch. We accept pull requests.

```bash
npm install
# For development:
npm start
# For production:
npm run build
```
